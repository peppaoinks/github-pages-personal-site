# 页眉、地图、书架与音乐

## 页眉动画

原站页眉固定，向下滚时字标从左移到中央并变大，回顶部恢复。把滚动距离归一化为 0–1 的 `--brand-shift`，通过 requestAnimationFrame 更新，scroll 监听 passive；CSS 计算位置、位移和字号，避免反复测量布局。

检查顶部、中间和完成状态，不撞导航/主题按钮；窄屏导航单独第二行。同步固定页眉高度与锚点留白，检查英文长导航；减少动态效果时取消非必要动画。教育日期用网格列对齐，保留预计毕业标记。

## 校园地图

原站教育经历下使用本地 Leaflet 1.9.4（保留 LICENSE）与在线 OSM 底图，本地库不等于底图离线可用。

移植第三方库要核对 CSS 的相对图片路径；按实际使用功能带齐发行包资源，原站缺少未启用控件的默认图片，详见建设记录，不能盲目只复制 JS/CSS。

- 坐标为 WGS84，Leaflet 顺序 `[纬度, 经度]`。从真实校园边界/关系核验中心，区别同名不同校区。
- 每校区独立双语名称、`periods` 数组和 expected 标记，可表示两个不连续就读阶段；校区时间和教育总时间分别维护。
- IntersectionObserver 接近视口后加载本地 CSS/JS 和瓦片，无 API 时降级；共享初始化 promise 避免重复建图。
- 提供校区定位、全图、缩放、标记和双语弹窗；语言切换更新现有对象，不重建地图。
- 关闭滚轮缩放；粗指针设备禁用单指拖拽，保留页面滚动，使用按钮和双指缩放。
- ResizeObserver 后 invalidateSize，全图状态重新适配范围；瓦片超时/失败时给状态提示和 OSM 外链，不阻塞主页。
- 主题滤镜仅作用底图 pane，控件、弹窗和标记独立配色；保持归属说明，替换供应者/增大流量前核对现行使用规则。

## 横向阅读/音乐轨道

用 flex、overflow-x:auto、scroll-snap-type 和卡片 snap 对齐；手机一张卡片占大部分宽度，下一张略露出。书封保持纵向比例，专辑方形。

按钮每次移动卡片宽度加实际 gap，方向键等价操作；到边界禁用按钮，scroll 和 ResizeObserver 更新状态。减少动态效果时即时滚动，无卡片或无该模块则跳过初始化。原站共用 setupShelf，移植时补齐模块存在检查，不假定所有页面都有两个轨道。

### 阅读

书名来自用户当前阅读，核对作者、版本和封面，记录 `assets/books/catalog.json`。原站 HTML 和清单手动同步，不宣称清单驱动生成；不把候选书单写成正在读。

### 音乐

用 Apple Music 目录连接器或官方来源核对曲目、艺人、专辑、歌曲 URL 和 artwork，记录 `assets/music/catalog.json`。目录可能采用艺人本名或不同版本，先核对匹配再显示。

用户只给歌手时，可以明确标记候选曲目；不能说是真实最近播放。卡片打开 Apple Music，不自动播放；网站卡片不意味着在个人账户中创建歌单，目录搜索不代表能读取私有播放记录。

## 可选扩展：定期同步

原建站基线 `637f237` 没有定时同步。后续另一项工作尝试从 Mac 音乐 App 读取最近播放，本 skill 形成时仍在进行，不能把它写成已交付功能。

用户另行要求同步时，先区分公开歌单、最近播放、收藏，并确认数据权限/设备能力。Mac 本地记录依赖该设备、音乐 App 与同步状态；GitHub 托管 Actions 无法直接读用户本机。

先手动验证“读取 → 去重/排序 → 目录匹配 → 更新清单及卡片 → 验收”，读取失败保留上次成功内容，不清空页面。再按用户周期接入可用调度器，两周不能假装等于每月 1/15 日或每月重置的日期间隔。

只公开必要曲目信息，不提交凭据/完整私人记录；调度、推送和通知遵从当前授权。没有新数据时不制造无意义发布。
