# 信息、视觉与双语

## 逐步补充，不编造

原站最初只有姓名和 GitHub 用户名，先发布关于、两个真实公开项目、联系入口和主题切换，再逐步加入学校、专业、年级、足球、音乐、教育、英语教学和照片。不要把“还在探索”改成特定研究兴趣，也不要为填满版面编造计划。

提问围绕当前缺项，可以跳过。多个文件与一串地点的对应不明确时，先看照片，再列“可辨认特征 → 地点”供确认，不按附件排列猜测。

文案写具体事实，少写口号和重复小标题。用户删去尴尬文案时同步处理两种语言和空布局。原站最终近况只有“最近在读 / Currently reading”和其下的“最近在听 / Currently listening”，删除“最近在忙”和未来计划；其他站点按用户意图安排。

## 文件与数据流

| 位置 | 维护内容 |
| --- | --- |
| `index.html` | 首屏、介绍、教育、项目、书架/音乐卡片、随笔/摄影空状态、QR、日期 |
| `style.css` | 设计变量、字体、响应式、主题和组件样式 |
| `script.js` | 翻译、偏好、`personalPhotos`、`photographyWorks`、`resumePdf`、页眉/轨道控件 |
| `assets/education-map.js` | 校园数据、延迟初始化、地图状态和语言 |
| `assets/books/catalog.json`、`assets/music/catalog.json` | 封面及外链来源，原站卡片由 HTML 维护，清单不是自动渲染数据源 |
| `.github/workflows/pages.yml` | 整理公开文件和发布 |

`photographyWorks=[]` 表示没有摄影作品；`resumePdf=""` 时隐藏简历按钮。添加 PDF 后确保它进入发布目录。空随笔集没有文章路由、Markdown 生成或 CMS。

## 字体、排版和品牌

原站从无衬线改为 Lora 与 Noto Serif SC，中文正文 500、标题 600，导航保留无衬线。只描述接近用户要求的阅读气质，不声称使用某产品专有字体。提供 Georgia/系统宋体等回退，核对远程字体失败时的排版。

首屏曾反复放大姓名、介绍和联系方式，并压缩空隙。用 `clamp()`、网格比例与最大宽度建立层级，在中英文和窄屏中实际检查，避免大固定字号导致英文溢出。

字标从 `fz` 改为斜体衬线 `felixzhou`，保留 24 与轨道圆形构图；主题改深绿与银色。文字/几何图形直接用 HTML/CSS/SVG 实现即可，需要照片或插画位图时再用图像生成能力。

浅色字标曾对比不足、字距过大，分别调整颜色与 letter-spacing，不因局部问题改所有正文。原站 CSS 有历史追加覆盖，维护前先看计算样式，必要时合并冲突，不无限追加规则。

## 双语与主题

`data-i18n` 对应 `translations.zh/en` 正文键，`data-i18n-label` 对应标签键。切换时同步 `html.lang`、按钮目标语言、title、description、aria-label、社交入口 title、当前相册 caption/alt，以及地图标记、弹窗和状态。默认 HTML 文案与字典一起维护。

正文写入用 `textContent`。它会删除子链接：给学校/俱乐部名称添加官网链接时，把句子拆成翻译文本 span 和独立 a，不给父段落整体设置翻译键。

localStorage 的读取/写入都捕获异常；没有保存的主题时参考系统主题。CSS 使用 `data-theme` 与颜色变量，同时更新 theme-color 和主题按钮标签。语言切换不重置照片、地图或主题。

## 链接与日期

核对学校、俱乐部、兴趣及社交入口的官方来源。没有独立官网时使用已核验的官方组织页面，并准确说明目的地。未提供地址时不要创建可点的假链接。新窗口链接设置合适的 rel。

移除联系方式时检查默认 HTML、翻译及生成数据。原站最终去掉个人微信号、保留公众号和邮箱；本 skill 不复制用户邮箱、二维码 payload 或个人照片。

页脚最后更新日期用用户时区，原站为北京时间。近况内容日期独立维护，修改页眉样式不意味着阅读内容发生变化。
